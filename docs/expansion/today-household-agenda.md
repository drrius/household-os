# Today: shared plans and deadlines

Today now combines open project tasks, project target dates, trip end dates, scheduled bookings, expanded calendar occurrences, and commitment notice/renewal deadlines. Overdue work remains visible; scheduled travel that has ended does not become perpetual overdue work. Upcoming entries cover today plus six days, including the next calendar week.

The domain mapper handles Zurich dates and clock changes. All-day dates remain civil dates and timed intervals use exclusive end boundaries. Ongoing stays/events remain visible. Explicit booking/calendar links coalesce overlapping occurrences into a booking entry with a separate calendar link; matching titles alone never suppress records. Recurring links retain the exact occurrence identifier. Both members' names describe responsibility. Completed/archived tasks, inactive projects, cancelled bookings and ended commitments are excluded. Calendar commitments retain their independent lifecycle until cancelled in Calendar.

Active commitments show their cancellation-notice deadline; a cancellation already requested shows a renewal follow-up instead. These are reminders only. No agenda command posts a financial event, changes a booking, or completes work. The existing progress meter is now labelled “Routines today” to avoid implying that it counts project tasks.

Calendar recurrence expansion is shared with the calendar screen without loading connection credentials. Read models authenticate, scope each query to the household, and page collection reads rather than silently accepting the default database row cap. A collection exceeding the safety bound fails explicitly. Parser warnings and pending/conflicted sync remain visible. Existing realtime mappings refresh Today for these source tables.

Verification: ten directly affected domain/calendar tests pass, including property coverage for stable ordering and horizon filtering, both Zurich DST changes, overlap deduplication, ongoing stays, cancellation follow-up, completed/archived exclusion and two-member responsibility. Targeted lint and TypeScript checking pass. Four browser cases pass across Chromium and mobile Safari: reveal upcoming deadlines, retain both linked destinations, avoid duplicate flight display, navigate through the real authentication gate, and remove a partner-completed task from refreshed props. These fixtures do not claim live two-person realtime or iCloud proof. Full integrated database/browser CI and CodeRabbit review remain release gates.
